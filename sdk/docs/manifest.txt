The manifest of your own game
=============================

So that the game works on PhoneXR right away and needs no patching, the AndroidManifest.xml needs:

  <uses-permission android:name="org.khronos.openxr.permission.OPENXR" />
  <uses-permission android:name="org.khronos.openxr.permission.OPENXR_SYSTEM" />

  <queries>
      <provider android:authorities="org.khronos.openxr.runtime_broker;org.khronos.openxr.system_runtime_broker" />
      <intent>
          <action android:name="org.khronos.openxr.OpenXRRuntimeService" />
      </intent>
      <intent>
          <action android:name="org.khronos.openxr.OpenXRApiLayerService" />
      </intent>
  </queries>

Without the <queries> block, Android hides the broker from targetSdk 30 on, the game does not find
the runtime and shows a black screen.

For someone else's build (from Quest, for example), PhoneXR adds all of this itself while patching:
the OPENXR and OPENXR_SYSTEM permissions, the <queries> block with the broker, INTERNET for the
tracking stream and the IMMERSIVE_HMD category on the launch screen. In your own game write them
right away — then there is nothing to patch.

The main activity has to be visible as a VR app:

  <category android:name="org.khronos.openxr.intent.category.IMMERSIVE_HMD" />

Mark headset features as optional, otherwise the APK will not install on a phone:

  <uses-feature android:name="android.hardware.vr.headtracking" android:required="false" />

Build for arm64-v8a. PhoneXR does not launch 32-bit builds.

Controls: PhoneXR pretends to be Oculus Touch controllers, so use the
/interaction_profiles/oculus/touch_controller profile. There is no stick: its values are always
zero, except for the "both fists" gesture. For raw hand data see docs/protocol.txt.

Your own hand tracking: if the game tracks hands with the camera itself, declare that in <application>
and PhoneXR will not turn on its own tracking when launching the game but will hand over the camera:

  <meta-data android:name="com.phonexr.OWN_HAND_TRACKING" android:value="true" />

Hands in OpenXR (the Touch controllers) then do not arrive — the game takes them from its own tracking.

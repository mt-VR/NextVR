The PhoneXR data stream
=======================

While tracking is on in PhoneXR, it sends a UDP packet of ASCII text 60 times per second:

  127.0.0.1:42424   to the Monado runtime
  127.0.0.1:42425   to the game through the SDK

One client holds a port. If there is no data, another app is already reading it.

Format (version PH6, the current one), numbers separated by spaces:

  PH6 <left hand> <right hand> <flags> <pinchL palmL pinchR palmR>

Each hand is 19 values:

  present fist index thumb x y z qx qy qz qw buttons stickX stickY thumbCurl indexCurl middleCurl ringCurl pinkyCurl

  present   1 if the hand is visible to the camera or a Joy-Con of that side is connected
  fist      a fist; index — the index finger only; thumb — the thumb only
            (in "hands only" mode all three are always 0)
  x y       the palm in the frame, 0..1; x grows to the right, y downwards
  z         closeness to the camera, 0..1 (1 is the closest)
  qx qy qz qw  rotation from the Joy-Con gyro; without a gyro 0 0 0 1
  buttons   Joy-Con button bits:
              1 A/X, 2 B/Y, 4 trigger, 8 grip, 16 menu, 32 stick click, 64 system

  stickX stickY  the Joy-Con stick, -1..1 (x to the right, y up)
  *Curl          the finger curl, 0 — fully straight, 1 — fully curled

After the flags come the pinch and the palm-to-face (0/1) for the left and the right hand.

Flags:

  1  positional tracking from the camera is on (6DoF)
  2  "hands only" mode: finger gestures press nothing

PH5 is the previous version without *Curl; PH4 is without the stick, the pinch and the palm.
The SDK reads PH6, PH5 and PH4.

Reading:

  Kotlin/JVM — com.phonexr.sdk.PhoneXRInput
  C/C++      — runtime/phonexr_input.h
